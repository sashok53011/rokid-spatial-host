# Возможности — что показывает это демо и как это увидеть

**Языки**: [English](CAPABILITIES.md) · [Deutsch](CAPABILITIES.de.md) · Русский (этот файл)

Это витрина возможностей: каждая функция, реализованная в
`rokid-spatial-host`, какой модуль её реализует, как продемонстрировать
её на устройстве и где живёт код. Используйте её, чтобы решить, **что
строить дальше** — идеи, вырастающие из этих возможностей, собраны в
`FUTURE.md`.

**Цель**: Rokid Max (3DoF) на Android-устройстве ARM64, мышь +
клавиатура. Сборка/установка/разрешения: см. в README раздел
«Build & run».

**Важно (если хост — телефон)**: перед входом в режим очков устройство
**обязательно нужно перевести в альбомный (ландшафтный) режим** —
приложение не делает это автоматически; в портретной ориентации режим
очков корректно не поднимется. Коробки-хосты это не касается.

Быстрая проверка любого изменения:

```powershell
adb logcat -s SpatialHost FilamentRenderer MaterialFactory ModelManager \
    IblBuilder PhysicsWorld RokidMaxBridge UsbDiagnostics
```

Условные обозначения статуса: **✅ проверено на устройстве** ·
**🟡 реализовано, нужна проверка на устройстве** ·
**⚪ теоретически / ещё не опробовано**

Чтобы попробовать F3 самостоятельно:

```powershell
Invoke-WebRequest 'https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/CesiumMan/glTF-Binary/CesiumMan.glb' -OutFile CesiumMan.glb
adb push CesiumMan.glb /sdcard/Download/
adb shell am force-stop com.rokid.spatialhost
adb shell am start -n com.rokid.spatialhost/.MainActivity
# press M until HUD shows model: CesiumMan — the figure walks
```

## Предлагаемый сценарий демо (5 минут)

1. **Запуск** → мост подключается, HUD показывает `ROKID_MAX`, видео
   стартует автоматически.
2. **Осмотритесь** → панели следят за головой; наведите взгляд на деку,
   кликните PLAY.
3. **`N` ×2** → переключение потоков; **`V` выкл** → цветная сфера +
   панели возвращаются.
4. **`M`** → переход к закинутой модели; перетаскивание вращает, колесо
   масштабирует.
5. **`B` `B`** → три объекта; **`P`** → они падают и складываются;
   схватите один и бросьте; **`DEL`** удаляет выбранный.
6. **`M`** → CesiumMan: фигура идёт (**F3** — самая новая возможность).
7. **`A`** → пауза на середине шага, **`A`** → продолжить; **`E`** →
   `ROUND-TRIP OK`.
8. **`H`** → чистый вид для фотографии.
